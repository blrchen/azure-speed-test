Frequently asked questions

How does this download speed test work?

The browser requests a short-lived read-only URL, downloads the full 100 MiB Azure Blob Storage test file, measures transferred bytes and elapsed time, then discards every data chunk without saving it.

Why are regions tested one at a time?

Parallel downloads would divide your local connection among several regions and make every result artificially slower. Sequential runs give each region the same opportunity to use the available bandwidth.

How much data does the test download?

The test always downloads 100 MiB from each selected region. For example, selecting six regions transfers up to 600 MiB plus protocol overhead because regions are tested one at a time.

What do Mbps and MiB/s mean?

Mbps means megabits per second and is comparable to typical internet plan speeds. MiB/s means mebibytes per second and uses binary units. Use the results control to switch units; both views come from the same measured transfer.

Why do results vary between runs?

Internet routing, Wi-Fi quality, VPNs, local resource pressure, regional congestion, browser scheduling, and competing traffic can change throughput. Repeat tests using the same size and regions before making a placement decision.
