Source and interpretation

How prices are selected

The lowest value is the minimum current {{ selectedOperatingSystem() }} {{ selectedPriceModeLabel() }} hourly rate published or derived for the VM size across Azure regions. Reservation totals are amortized across their full term; Windows reservation estimates retain the PAYG software surcharge and do not model Azure Hybrid Benefit. Spot capacity can be evicted. Monthly cost is an estimate based on 730 hours.

Availability is separate

A published price does not guarantee quota, capacity, zone support, or deployment eligibility for a particular subscription. Subscription restrictions are intentionally excluded.

Prices: Azure Retail Prices API version {{ data.source.retailPrices.apiVersion }}. Specifications: Resource SKUs API version {{ data.source.resourceSkus.apiVersion }}.
